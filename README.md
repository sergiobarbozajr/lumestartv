# LumeStarTV

App de IPTV para Android TV, por Sérgio Barboza Júnior.

- **Simulador navegável:** a página LumeStarTV no Claude (versão de TV com controle virtual).
- **Instalar na TV:** baixe `LumeStarTV.apk` em [Releases](../../releases/latest). Depois disso, as novas versões chegam por **Configurações › Atualização do app**.
- **Como é publicado:** cada envio para a `main` compila, testa no emulador (abertura, menu, navegação pelo controle e fluidez) e só publica se o teste passar.

## Entregas
1. Base: abertura (buraco negro, big bang, nome com plasma, apagão, buraco de minhoca), menu lateral pelo controle, atualização pelo GitHub. **(0.1.0)**
2. Listas: contas IPTV (Xtream), M3U/M3U8/JSON/TXT organizadas nas abas, pesquisa com teclado virtual, Minha lista, Visto e Continuar assistindo.
3. Reprodutor: linha do tempo, imagem, tela (faixas pretas), som, legendas, dublagem, transmissão de rede estilo VLC e proxy.
4. Extras: IA de imagem e de áudio, Assistente IA, Streaming e Músicas, demais configurações.

Fontes: Inter e Creepster (licença SIL OFL, em `app/src/main/assets/licencas`).
